# 硬性约束

1. **公式只写 `formula`，引用按 Excel 行号（1-based）**
   `data` 第 0 行是 Excel 第 1 行。公式里 `H3:H10` 对应 `data` 下标 2~9。
   公式单元格不要同时乱填 `value`；要给缓存值时必须等于公式结果。
   跨表引用（`Sheet1!A1`）、VLOOKUP 等仍能导入，但预览不求值，需在编辑器里核对。

2. **合并区只在左上角放值**
   `"merges": ["A1:I1"]` 时第 0 行只写 A1，B1~I1 留 `null`。其它单元格写值会被合并隐藏。
   合并区不能重叠，转换器会跳过重叠项并警告；单格合并也会被跳过。

3. **普通单元格不要写换行**
   `"a\nb"` 会变成单行文本（Univer 普通值不保留换行）。需要多行就拆成多行单元格，
   或用富文本（当前 spec 不支持，勿尝试 `p` 字段）。

4. **样式尽量命名复用**
   `styles` 里定义一次，单元格写 `style:"header"`。内联对象也支持，但重复定义容易漂移。
   数字格式属于单元格样式：金额列、百分比列要各自给 `numberFormat`，否则显示原始小数。

5. **列宽单位是 px，不是字符**
   默认 88px。名称列建议 120~160，金额列 80~110，序号列 40~60。宁宽勿窄，避免编辑器里截字。

6. **冻结用 rows/columns，不要手写 Univer 字段**
   `freeze:{rows:2,columns:0}` 会生成正确的 `{startRow,startColumn,xSplit,ySplit}`。
   冻结行数应覆盖标题+表头，否则滚动时表头会跑掉。

7. **隐藏工作表仍会参与引用计算**
   `hidden:true` 只影响标签页显示。预览里会带「隐藏」标记，方便核对；交付前确认是否真要隐藏。

8. **强制自检**
   转换后必须看 stderr 警告并逐条修正；再用 Chrome 截图核对：
   - 合计/占比是否与明细一致（预览公式自算，能抓出区域写错）；
   - 合并区是否错位、表头是否被截断；
   - 金额是否千分位、百分比是否 ×100；
   - 冻结提示与预期行数一致。
   编辑器与预览的字体度量略有差异，列宽以编辑器实际打开为准。
